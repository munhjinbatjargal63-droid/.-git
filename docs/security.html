Security Lab

Кибер аюулгүй байдлын үндсэн ойлголт, нууц үгийн хамгаалалт болон фишинг халдлагыг таних мэдлэгээ шалгах сургалтын лаборатори.

01. Password Security

Нууц үгийн аюулгүй байдал нь мэдээллийн хамгаалалтын чухал хэсэг юм. Урт, давтагдашгүй нууц үг ашиглах хэрэгтэй.

Доорх талбарт зөвхөн жишээ нууц үг бичиж шалгана уу. Жинхэнэ нууц үгээ бүү оруулаарай.

02. Phishing Awareness

Фишинг гэдэг нь хуурамч мессеж, имэйл, вебсайтаар дамжуулан хэрэглэгчийн мэдээллийг авахыг оролддог цахим залилан юм.

Жишээ: "Таны данс хаагдах гэж байна. Доорх холбоосоор яаралтай нэвтэрнэ үү."

Ийм мессеж ирвэл хамгийн зөв үйлдэл аль вэ?

03. Security Best Practices

Кибер аюулгүй байдлын үндсэн зөвлөмжүүд:

✓ Давтагдашгүй, урт нууц үг ашиглах

✓ Хоёр шатлалт баталгаажуулалт идэвхжүүлэх

✓ Программ хангамжаа тогтмол шинэчлэх

✓ Сэжигтэй холбоос дээр дарахгүй байх

✓ Чухал мэдээллээ нөөцлөх
