Сургалтын тэмдэглэл


IP Address: Сүлжээнд төхөөрөмжийг таних хаяг.

Subnet Mask: Сүлжээний болон төхөөрөмжийн хэсгийг ялгана.

Network Address: Тухайн дэд сүлжээний хаяг.

Broadcast Address: Дэд сүлжээний бүх төхөөрөмжид мэдээлэл хүргэхэд ашиглагдах хаяг.

CIDR: Сүлжээний хэсэгт хамаарах битийн тоо.
